# MBTI 人格模型设计文档

## 一、MBTI 理论基础

MBTI（Myers-Briggs Type Indicator）基于荣格心理类型理论，通过四个维度的偏好组合定义16种人格类型。

### 四个维度

| 维度 | 两端 | 含义 |
|------|------|------|
| **精力来源** | E（外向）↔ I（内向） | 你从哪里获得能量 |
| **认知方式** | S（感觉）↔ N（直觉） | 你如何接收信息 |
| **决策方式** | T（思考）↔ F（情感） | 你如何做决定 |
| **生活态度** | J（判断）↔ P（感知） | 你如何应对外部世界 |

### 16种人格类型速览

| 类型 | 中文名 | 核心特质 |
|------|--------|----------|
| INTJ | 建筑师 | 战略思考，独立，远见卓识 |
| INTP | 逻辑学家 | 逻辑分析，创新，好奇心驱动 |
| ENTJ | 指挥官 | 领导力，果断，目标导向 |
| ENTP | 辩论家 | 敏捷思维，善于辩论，创意无限 |
| INFJ | 提倡者 | 洞察力，理想主义，深刻的共情 |
| INFP | 调停者 | 理想主义，创造力，善良温柔 |
| ENFJ | 主人公 | 激励他人，共情力强，天生领导者 |
| ENFP | 竞选者 | 热情，创造力，自由精神 |
| ISTJ | 物流师 | 可靠，务实，有责任感 |
| ISFJ | 守卫者 | 守护，细腻，忠诚奉献 |
| ESTJ | 总经理 | 管理力，效率，规则导向 |
| ESFJ | 执政官 | 温暖，关怀，重视和谐 |
| ISTP | 鉴赏家 | 务实，灵活，动手能力强 |
| ISFP | 探险家 | 艺术感，自由，活在当下 |
| ESTP | 企业家 | 行动力，冒险，临场应变 |
| ESFP | 表演者 | 热情，乐观，享受生活 |

## 二、评分算法设计

### 2.1 题型结构

每道题属于8个维度之一：E、I、S、N、T、F、J、P。

- 正向题（direction="forward"）：选择「是」→对应维度得分+权重
- 反向题（direction="reverse"）：选择「是」→对立维度得分+权重

### 2.2 得分计算

```typescript
function calculateScores(answers: Answer[]): DimensionScores {
  const scores = { E: 0, I: 0, S: 0, N: 0, T: 0, F: 0, J: 0, P: 0 }
  
  for (const a of answers) {
    const q = questionBank[a.questionId]
    if (!q) continue
    
    const score = q.weight || 1
    const isAgree = a.answer === 'agree'
    
    if (q.direction === 'forward') {
      scores[isAgree ? q.dimension : oppositeOf(q.dimension)] += score
    } else {
      scores[isAgree ? oppositeOf(q.dimension) : q.dimension] += score
    }
  }
  
  return scores
}
```

### 2.3 类型判定

```
比较每对维度的得分：
  E >= I ? 'E' : 'I'
  S >= N ? 'S' : 'N'
  T >= F ? 'T' : 'F'
  J >= P ? 'J' : 'P'
```

### 2.4 各维度百分比

```
E/I: E/(E+I) vs I/(E+I) → 百分比
S/N: S/(S+N) vs N/(S+N) → 百分比
以此类推...
```

### 2.5 置信度

```
confidence = min(
  |E-I|/(E+I),
  |S-N|/(S+N),
  |T-F|/(T+F),
  |J-P|/(J+P)
)
```
值范围 0-1，越高说明该类型的判定越明确。如果某个维度接近50/50（如E=8, I=7），则该维度置信度低，建议用户重新测试或在结果页标注「边缘型特征」。

## 三、题库设计标准

### 3.1 基本规格

| 参数 | 值 |
|------|-----|
| 总题数 | 60 |
| 每维度对题数 | 15（E/I对、S/N对、T/F对、J/P对） |
| 正向/反向比 | 约30:30（1:1平衡） |
| 评分量级 | 2级：「符合」/「不符合」 |
| 题目权重 | 1-3（反映区分力） |

### 3.2 题目场景覆盖

每个维度对（15题）覆盖以下生活场景：

| 场景类别 | 示例场景 | 题数 |
|----------|----------|------|
| 社交行为 | 聚会、认识新朋友、独处偏好 | 3 |
| 信息处理 | 阅读习惯、解决问题的方式、学习偏好 | 3 |
| 决策方式 | 做决定时先想什么、如何说服别人 | 3 |
| 生活规划 | 旅行计划、日常安排、截止日期 | 3 |
| 工作偏好 | 团队合作、独立工作、领导角色 | 3 |
| **合计** | | **15** |

### 3.3 题目质量标准

- 每题针对单一维度，不跨维度（如不能同时涉及E/I和T/F）
- 生活化语言，避免学术术语（如不用「认知偏向」「感知功能」等词）
- 场景具体可想象（如「周末你更想和朋友聚会还是在家看书」）
- 正向和反向题语义自然，不让用户察觉「这题在测什么」
- 权重：简单区分维度核心特征的题＝权重1，中等＝2，高区分力＝3
